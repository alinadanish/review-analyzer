│                File                │                              What we pull out of it                               │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ CSV, TSV                           │ each column, by its header name, with sample values                               │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Excel (.xlsx, .xls)                │ every sheet, as columns with headers; dates and long numbers written out properly │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Text, JSON, XML, HTML, log files   │ the text as it stands                                                             │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Word (.docx, .doc)                 │ all text: body, footnotes, page headers, table cells                              │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ PowerPoint (.pptx, .ppt)           │ slide text and speaker notes                                                      │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ PDF                                │ the text; pages that are scans go through OCR                                     │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Images (PNG, JPEG, TIFF, BMP, GIF) │ text read out of the picture by OCR                                               │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Email (.eml, .msg)                 │ sender, recipients, subject, date, body, and each attachment as a file of its own │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Outlook mailbox (.pst)             │ every mail, contact and meeting inside, in every folder                           │
├────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────┤
│ Zip                                │ each file inside, up to three levels deep                                         │
